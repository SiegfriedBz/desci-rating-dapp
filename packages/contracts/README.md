`foundry.toml`: `src` / `out` / `libs = ["lib"]`, `solc_version = "0.8.24"`, optimizer on (`optimizer_runs = 200`). RPC `base_sepolia` = `BASE_SEPOLIA_RPC_URL`. Etherscan `base_sepolia` key = `ETHERSCAN_API_KEY` (used by `forge script --verify`).

Env used by this package’s deploy / HelperConfig (see repo-root `.env.example`):

- `BASE_SEPOLIA_RPC_URL`
- `PRIVATE_KEY` (deployer; becomes `owner` on `RatingController`)
- `ORACLE_AGENT` — public address written as `RatingController.oracleAgent` at deploy. `HelperConfig` reads it only on Base Sepolia (`84532`); Anvil uses `makeAddr("oracle")` instead. This is the only address allowed to call `fulfillPhase1` (`onlyOracleAgent`). `owner` cannot fulfill; it can rotate the oracle via `setOracleAgent` and cancel pending requests.
- `ETHERSCAN_API_KEY`

## Folders

### `src/`

`RatingController.sol` — on-chain request/fulfill state machine and oracle gateway for Phase-1 ratings (`UNLICENSED`).

Constructor: `msg.sender` is `owner`; `_oracleAgent` must be non-zero.

`getRequestId(targetUal)` is `keccak256(abi.encodePacked(targetUal))`. Ratings are stored at `ratings[requestId]`.

**Phase** (`Unrated`, `Phase1Completed`, `Phase2Completed`, `Phase3Completed`).

**RatingRecord**: `phase`, `isPending`, `phase1Score`, `phase2Score`, `phase3Score`, `rKaUal`.

Functions:

- `requestPhase1(targetUal)` — non-empty UAL; `phase == Unrated`; not already pending. Sets `isPending` and emits `Phase1Requested(requestId, targetUal, requester)`.
- `fulfillPhase1(targetUal, score, rKaUal)` — `onlyOracleAgent`; pending; `phase == Unrated`; `score` in `[0, 100]`; non-empty `rKaUal`. Sets `Phase1Completed`, clears pending, writes `phase1Score` and `rKaUal`. Emits `Phase1Fulfilled`.
- `cancelPendingRequest(targetUal)` — owner or oracle agent; pending. Clears `isPending` without changing phase. Emits `RequestCancelled`.
- `setOracleAgent(_newOracleAgent)` — `onlyOwner`; non-zero. Emits `OracleAgentUpdated`.
- `getRatingByUal` / `getRating` — view; zeroed record if never requested.

Errors: `UnauthorizedCaller`, `InvalidOracleAgent`, `EmptyUal`, `EmptyRKaUal`, `InvalidScore`, `AlreadyPending`, `NotPending`, `InvalidPhase`.

There are no `request`/`fulfill` functions for Phase 2 or Phase 3.

### `script/`

- `RatingController.s.sol` — `RatingControllerScript.run()`: `HelperConfig.getConfig().oracleAgent`, then `new RatingController(oracleAgent)` under `vm.startBroadcast()` (broadcaster is `owner`).
- `HelperConfig.s.sol` — `NetworkConfig { oracleAgent }`. Chain `84532` (Base Sepolia): `vm.envAddress("ORACLE_AGENT")`. Chain `31337` (Anvil): `makeAddr("oracle")`, cached after first create. Any other chain id reverts `HelperConfig__UnsupportedChainId`.

### `test/`

Forge tests. `RatingController.t.sol` deploys via `RatingControllerScript` on Anvil (`31337`): constructor, request, fulfill, cancel, admin, views. `HelperConfig.t.sol`: Anvil, Base Sepolia, unsupported chain id.

### `scripts/`

`export-abi.mjs` — reads Forge artifact `out/RatingController.sol/RatingController.json` and broadcast `broadcast/RatingController.s.sol/84532/run-latest.json` (`RatingController` `CREATE`). Writes `ts/ratingControllerAbi.ts` and `ts/deployments.ts`. If the broadcast file or CREATE is missing, uses fallback `0x9D53bdabB8Eb1c724323c5542d5C344B2d84B2Cc`.

### `ts/`

TypeScript sources compiled by `tsc` (`tsconfig.json`: `rootDir` `./ts`, `outDir` `./dist`).

### `lib/`

`forge-std` (Foundry).

## Roadmap

`RatingController` today is the Phase-1 slice of a three-phase request/fulfill state machine (same pattern as Chainlink VRF `request` / `fulfill`: a request only sets `isPending` and emits; only the oracle may advance phase after off-chain work). The `Phase` enum and `phase2Score` / `phase3Score` fields are already on `RatingRecord`; they are unused until the functions below exist.

**Next on this contract (Phase 2, then Phase 3)** — sequential, same pending lock:

1. **Phase 2 request** — eligible only when `phase == Phase1Completed` and not pending. Emits a Phase-2 request event for off-chain HITL. Reviewer assignment is a separate `ReviewerPool` (not in this package): enroll/stake, Chainlink VRF cohort draw, optional disjoint redraw if no consensus. Draft: `RatingController` would own `ReviewerPool`.
2. **Phase 2 fulfill** — oracle-only, pending, still in Phase 1 completed. Writes the Phase-2 score, sets `Phase2Completed`, clears pending. Also stores a wet-lab recommendation boolean; that flag is what gates Phase 3.
3. **Phase 3 request** — eligible only when `phase == Phase2Completed` **and** wet-lab was recommended. Emits a Phase-3 request event for off-chain wet-lab.
4. **Phase 3 fulfill** — oracle-only. Writes the Phase-3 score, sets `Phase3Completed`, clears pending.

R-KA lifetime (OriginTrail, not this contract): mint once in Phase 1 (`rKaUal` already stored here); Phase 2 and 3 `update()` that same asset. No new NFT.

Not decided in v0: proxy/`RatingController` upgradeability vs keeping the mapping on an immutable deploy.
